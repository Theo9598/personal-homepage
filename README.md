# Theo Zhang Portfolio

A dynamic HyperFrame-style personal homepage for Theo Zhang, built with Vite,
React, and TypeScript. The site is static, GitHub Pages-ready, and keeps editable
content in `src/data/profile.ts`.

The homepage uses a single-screen console layout rather than a traditional
scrolling page. The dynamic layer now lives as a full-page ambient background,
with GitHub repositories from `github.com/Theo9598` surfaced as the primary
interactive frame universe.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production artifact is emitted to `dist/`.
